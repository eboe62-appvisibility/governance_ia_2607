# Review Template
(Request template for reviewing project decisions, Architectural Decision Records, and governance documents)

## Purpose

Use this template whenever an approved or proposed decision requires an independent review before adoption, revision, or implementation.

Examples include:

- Architectural Decision Records (ADRs)
- governance documents
- technical proposals
- project policies
- design decisions
- other project decisions

---

## Prohibited Actions

Do not:

- rewrite the reviewed document automatically
- introduce new decisions without authorization
- expand the approved scope
- modify project governance
- assume evidence that has not been provided
- mix facts with assumptions

Implementation requires a separate Execution Request.
